# STE Checklist

> Use this checklist before you deliver STE text. Answer each question. If the
> answer is "no", correct the text. The checklist follows the STE writing
> rules and does not replace the official document.

## Words

- Is each word an approved word or a correct technical noun?
- Is each approved word used as one part of speech only?
- Is each approved word used with one approved meaning only?
- Did you replace each unapproved word with an approved word?

## Nouns

- Is each noun cluster 3 words or fewer?
- Is each noun cluster clear?

## Verbs

- Do you use only the approved verb forms?
- Do you use the active voice? (In descriptions, is the passive voice used
  only when the agent is not known?)
- Did you remove the "-ing" verb forms?
- Did you remove the complex verb tenses with auxiliary verbs?

## Sentences

- Is each procedure sentence 20 words or fewer?
- Is each descriptive sentence 25 words or fewer?
- Is there one instruction in each sentence?
- Are the subject, the verb, and the article present in each sentence?

## Procedures

- Does each instruction start with the imperative?
- Are the steps in the correct sequence?
- Is a vertical numbered list used for a sequence of steps?
- Are there 6 sequential steps or fewer in each paragraph?

## Paragraphs

- Is there one topic in each paragraph?
- Are there 6 sentences or fewer in each paragraph?

## Safety

- Does the warning or the caution come before the step?
- Does the safety instruction start with a command or a condition?
- Does it tell the risk and how to prevent the risk?

## Layout

- Is a vertical list used for parallel items?
- Is the same word used for the same idea each time?
- Are synonyms removed?

## Last check

- Read the text one more time. Is the meaning correct?
- Can a reader who does not know English well understand the text?
- Are there items you could not confirm? If yes, verify them against the
  official document. See `official-source.md`.
