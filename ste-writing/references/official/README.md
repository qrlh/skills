# Put your official copy here

This folder is empty on purpose. The skill does not include the ASD-STE100
document, because ASD owns the copyright.

If you want an instance to read the document directly, put your own official
copy in this folder:

    ASD-STE100_ISSUE9.pdf

You can also add a Markdown conversion next to it. An instance reads Markdown
faster and more reliably than a PDF, and instances look for this file first:

    ASD-STE100_ISSUE9.md

Get a free official copy from https://asd-ste100.org.

Do not share the skill with these files inside it. The copies are for your
use only. The `.gitignore` of this repository excludes both files.
