# The Official Standard

> This skill does not include the ASD-STE100 document. ASD owns the copyright
> and the trademark. The user must add the official copy. This keeps the skill
> copyright-compliant.

## Why the document is not in this skill

The skill gives paraphrased guidance and examples. This is enough for most
tasks. But the guidance is not the authority. The official document is the
authority. Read the official document for the exact rule wording, the full
explanations, the official examples, and the complete dictionary.

## How to get the official copy

The document is free. Get it from ASD.

- Official site: https://asd-ste100.org
- Request page: the site has a form for a free official copy.
- The current issue is Issue 9 (2025-01-15).

## Where to put the copy (for the user to do manually)

If you want an instance to read the document directly, add your own copy to
this skill. Put the file here:

    ste-writing/references/official/ASD-STE100_ISSUE9.pdf

You can also add a Markdown conversion of the document. An instance reads
Markdown faster and more reliably than a PDF. Put the conversion here:

    ste-writing/references/official/ASD-STE100_ISSUE9.md

Do not commit or share the skill with these files inside it. The copies are
for your use only.

## When to consult the official document

Consult the official document in these cases:

- You are not sure if a word is approved.
- You are not sure of the approved meaning of a word.
- You are not sure how a rule applies to a difficult sentence.
- The user asks for the exact rule wording.
- The user asks for the official examples.

## How to consult it

1. Look at the rule map below. Find the correct section and rule number.
2. Look for `references/official/ASD-STE100_ISSUE9.md` first. If it is
   present, search it for the rule number and read that part.
3. If the Markdown file is not present, look for
   `references/official/ASD-STE100_ISSUE9.pdf` and read that page range.
4. If neither file is present, tell the user. Give the exact section and rule
   number. Point the user to https://asd-ste100.org.
5. Do not guess. If you cannot confirm, say so.

## A note on document access

The official PDF can have copy protection. If an instance cannot extract the
text, it can read the page as an image instead. A Markdown conversion at
`references/official/ASD-STE100_ISSUE9.md` removes this problem. But the best
method is always the same: find the correct rule number first, then read only
that rule.
