# Slop words and replacements

> This list extends the STE dictionary for one task: remove "AI slop" from
> prose. The lists come from the ste-lint.py checker (MIT, Ege Celebi) and
> match what it counts. STE itself does not define these lists.

## Replacement pairs

Use the short word. Do not use the long word.

| Use | Do not use |
|-----|------------|
| start | begin, commence, initiate |
| use | utilize, leverage |
| help | facilitate |
| make sure | ensure |
| before | prior to |
| after | subsequent to |
| about | regarding, concerning |
| get | obtain, acquire |
| show | demonstrate |
| also | additionally, furthermore, moreover |
| many | numerous, myriad, a plethora of |
| to | in order to |
| if | in the event that |
| because | due to the fact that |

## Marketing adjectives

Do not use these words in technical text:

seamless, robust, powerful, cutting-edge, effortless, world-class,
next-generation, revolutionary, blazing, lightning-fast, elegant, delightful,
turnkey, best-in-class, state-of-the-art, game-changing, battle-tested,
enterprise-grade, supercharge, unlock, unleash, empower.

## Phrasal verbs

Replace the phrasal verb with one plain verb:

| Use | Do not use |
|-----|------------|
| start | spin up, kick off, ramp up |
| stop | spin down, tear down |
| contact | reach out |
| examine | dive into, drill down |
| release | roll out |
| return | circle back |

## Hedge phrases

Delete these phrases. They add no information:

- it is important to note
- it should be noted
- it is worth noting
- please note that
- as mentioned above
- as noted above
